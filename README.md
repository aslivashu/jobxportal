# JobXPortal

A full-stack job portal web application.

This repository contains:

- `backend/` — Node.js + Express API server.
- `frontend/` — React + Vite frontend (see `frontend/README.md`).

Quick start

Backend

```bash
cd backend
npm install
npm run dev
```

Frontend

```bash
cd frontend
npm install
npm run dev
```

See `frontend/README.md` for frontend-specific notes.
